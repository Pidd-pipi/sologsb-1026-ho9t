# 儿童自然拼读课程编排工具

面向自然拼读教研组与带班老师的纯前端课程设计工具。教研组维护**课程模板**，老师为每个班级建立只保存**相对模板覆盖项**的**班级方案**；模板升级时保留本地改动，移除活动与改向依赖列为待处理；平板断网改动回来可三路合并。

## 两层模型

- **课程模板（教研组）**：有不可变的发布版本和一份可继续编排的草稿。发布新版本不覆盖任何班级。
- **班级方案（老师）**：只钉住某个模板版本并保存差异——
  - 课程级字段覆盖（标题、等级、年龄、目标）；
  - 活动字段覆盖（依赖、时长、提示语、无障碍、反馈等），与模板值一致的覆盖会自动清除；
  - 班级自建活动、本班停用活动、本班顺序；
  - 升级/合并产生的待处理事项。
- 质量检查、学习路径、版本比较、复制结果全部由「模板版本 + 覆盖项」实时解析，模板或依赖一变立即按当前班级方案重算。

## 模板升级

- 班级继续钉在旧版本上，其他班级不受教研组发版影响。
- 老师在「版本与复用」页主动升级：
  - 本地依赖、时长、说明等覆盖原样保留，模板改过的未覆盖字段跟随新版；
  - 模板移除的活动 → `待处理·活动移除`，可**转为本班活动**（带回原本地覆盖）或跟随模板移除；
  - 依赖被删除/改向 → `待处理·依赖改向`，可跟随新依赖，或保留旧依赖（系统把旧活动从历史版本补回本班）；
  - 模拟处理失败时保留**班级升级草稿**（含已算好的覆盖与待处理），可继续裁决后**重试提交**或放弃。

## 断网平板编辑

- 在班级页点「平板断网编辑」进入断网会话：进入时冻结模板版本与覆盖基线，之后的修改以操作队列保存（字段、依赖、顺序、停用、新增、删除）。
- 可模拟「教研组在断网期间发布新版本」和「他机修改同字段」。
- 「恢复联网并合并」做字段级**三路合并**（基线 / 平板 / 服务器侧）：
  - 只有一边改 → 直接采用；
  - **同一字段两边都改且值不同 → 两份都保留**，生成 `待裁决·双方修改`，质量检查页并列展示两份取值，可采用本机、采用他机或继承模板；
  - 服务器侧已发新版 → 合并同时完成结构升级（新增活动并入，移除/改向列入待处理）；
  - 合并失败保留会话草稿，可重试。

## 其他功能

- 音素、单词、句子、练习四类活动；难度、时长、提示语、无障碍说明、练习反馈。
- 复选框建立前置依赖，检测循环依赖、失效/后置引用、提前使用音素、相似音混淆、例句过长、练习缺反馈、无障碍缺失。
- 手机 / 平板 / 桌面三种学习路径宽度预览。
- 模板版本间比较，以及「当前模板版本 / 本班方案 / 升级草稿 / 任意模板版本」任意两侧按实时解析结果比较。
- 复制模板（独立新 id）、复制班级方案（同模板新版本上的全新覆盖）。
- 全部数据自动保存到 localStorage，撤销/重做（Ctrl/⌘+Z、Y）、Alt+←/→ 切换工作台。

## 验证

```bash
npm install
npm run check      # Svelte / TypeScript 检查（0 错误 0 警告）
npm run build      # 生产构建到 build/
```

核心算法（覆盖解析、升级保留、待处理裁决、三路合并冲突、按方案重算）有 38 项断言脚本：

```bash
node -e "require('esbuild').build({entryPoints:['scripts/verify.mts'],bundle:true,platform:'node',format:'cjs',outfile:'scripts/.verify.cjs',loader:{'.mts':'ts'}})" && node scripts/.verify.cjs
```

## 本地开发

```bash
npm run dev
```

开发服务器监听 5173。数据仅保存在当前浏览器，可用页头「重置演示」恢复内置数据：两套模板（春季版/秋季版，后者删除口型活动、改向 a-8 依赖）与四个班级（含一个升级失败待重试的班级），便于演示全部场景。

## 技术栈

SvelteKit + Svelte 5 + TypeScript + Carbon Components Svelte + Vite，localStorage 持久化，Nginx 静态部署。
